                    Bulk onboard (CSV)

                    Creates every account in the file, assigns each one a Microsoft 365 Business Standard license automatically, and (if you provide a PreferredEmail) sends that person their own credentials directly. Columns: FirstName, LastName, Username, Department, UsageLocation, PreferredEmail, plus an optional JobTitle column if you want each person's position set too (UsageLocation is a 2-letter country code, e.g. PH; PreferredEmail is optional — the new employee's own personal/external email to receive their sign-in details). Username only — your own sign-in domain is added automatically, same as the single form above. Group assignment still happens afterward via Manage User or the Distro List bulk CSV, once accounts exist.

                    Offboarding

                    Offboard a user

                      This will immediately:
                      • Remove this user from every group and distribution list they belong to
                      • Revoke all their active sign-in sessions (signed out everywhere)
                      • Reset their password to a random value — not sent to them (this is a lockout, not a handoff)
                      • Schedule their license(s) for removal in 30 days, tracked on the Pending list below

                      Licenses are not removed immediately — see the note under "Pending license removals" for why this needs a manual step after 30 days rather than firing on its own.

                      Pending license removals

                      Users offboarded 30+ days ago whose license(s) haven't been removed yet. Nothing here happens automatically — this app can't authenticate in the background with nobody signed in, so processing is a deliberate click.

                      Bulk offboard (CSV)

                      Offboards every user in the file — removes all group memberships and any direct SharePoint site access, revokes sessions, resets password silently, and marks each for the same 30-day license removal as a single offboard. Column: Email. A results CSV (Email, Status) downloads automatically once it finishes, for your records.

                      Guest User

                      Adds an external person as a guest in your directory — for a partner, contractor, or vendor who needs limited access. This does not send them any email or invitation; they won't know this happened until you decide to share access some other way.

                      Audit Trail

                      Recent admin activity

                      Directory audit log from Entra ID — user, group, app, and device changes made through the admin portal or Graph API. Most tenants keep roughly 30 days of history without an Audit Premium add-on.

                      Mail

                      Email activity report

                      Per-user send/receive/read counts from Microsoft Graph's real activity reports API. This is an aggregate summary, not a per-message trace — Graph has no API for looking up an individual email's sender, recipient, subject, or delivery status. For that, use the real tool linked below.

                      Message trace & mail flow rules

                      These aren't things this app can build — Microsoft Graph has no API for per-message trace, transport rules, or anti-spam/blocked-sender lists at all. That's Exchange-specific functionality, only reachable through the Exchange admin center directly.

                      Install App

                      Works on your phone or your computer. Same sign-in, same data — it just opens like an app instead of a browser tab. No app store, nothing to buy.

                      iPhone & iPad

                      This looks like your device
                      1. Open this site in Safari — it has to be Safari specifically, Chrome and other browsers on iOS aren't allowed to do this.
                      2. Tap the Share icon (the square with an arrow, in the bottom toolbar).
                      3. Scroll down and tap Add to Home Screen.
                      4. Tap Add in the top-right corner.

                      iOS doesn't let any button do this automatically — Apple requires it to be done manually from Safari's own Share menu.

                      Android

                      This looks like your device
                      1. Open this site in Chrome.
                      2. Tap Install now above if it's showing, or the ⋮ menu → Add to Home screen / Install app.
                      3. Confirm by tapping Install.

                      Windows & Mac

                      This looks like your device
                      1. Open this site in Chrome or Edge.
                      2. Tap Install now above if it's showing, or click the install icon at the right side of the address bar.
                      3. Click Install in the popup.

                      Firefox and Safari on desktop don't support installing sites as apps — Chrome or Edge only, for now.
